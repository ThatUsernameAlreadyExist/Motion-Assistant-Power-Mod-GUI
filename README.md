# Motion-Assistant-Power-Mod-GUI
New GUI for Motion Assistant utility

Build: 
- Requirements: Visual Studio 2022, Avalonia, Fody Costura
- To start only UI in VS: pmgui project properties->Debug->Open Debug Launch Profiles->In commad line arguments input "debug" string.
- For real testing with Motion Assistant - paste pmgui.exe, pmgui.exe.config and Localization in 'pmgui' folder inside MA Power Mod installation dir, e.g. 'C:\Program Files\Motion Assistant\pmgui'
